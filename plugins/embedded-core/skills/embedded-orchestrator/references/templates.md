## Backlog entry

Append one row per gap to the backlog table:

| ID | Date | Type | Skill | Gap | Exposed by | Proposed scope | Priority | Status |
|---|---|---|---|---|---|---|---|---|
| B-0NN | YYYY-MM-DD | new or update | skill name | what is missing or wrong | the task that hit it | what it should cover | H, M, or L | open |

Use the next free ID; update an existing row instead of adding a duplicate.
